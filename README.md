# Amazon Weekly Product Report Skill

This repository contains a Codex skill for Amazon weekly product reports and a sanitized HTML reference report.

## Contents

- `amazon-weekly-product-report/SKILL.md`  
  Skill instructions for writing, improving, anonymizing, and exporting Amazon weekly product reports.

- `examples/weekly-product-report-anonymized-2026-06-22.html`  
  A sanitized HTML example report using consulting-style blue/white layout. Business metrics are preserved, while store, product, ASIN, SKU, campaign, search term, and competitor identifiers are anonymized.

## Notes

- Do not add raw exports, `.env` files, screenshots with account data, QR codes, or original marketplace identifiers to this repository.
- HTML and Feishu/Lark export are optional output modes in the skill. Use them only when requested by the user.
